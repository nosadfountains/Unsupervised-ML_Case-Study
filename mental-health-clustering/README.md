# Data credits

OSMI Mental Health in Tech Survey 2016 by Open Sourcing Mental Illness (OSMI), uploaded to Kaggle:
https://www.kaggle.com/datasets/osmi/mental-health-in-tech-2016?select=mental-heath-in-tech-2016_20161114.csv

License: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)

You can find the original data from the download in `data/raw/`, unchanged and under its original file name. The codebook `data/column_map.csv` quotes the original survey questions and is shared under the same license.

The project overview and the instructions for running the notebook are in the README in the repository root.
